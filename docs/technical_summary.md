# Technical Project Summary

## Saudi Data Internship Readiness Map

This document summarizes the technical workflow used to analyze Saudi data-related internship and job postings and transform the findings into a practical readiness roadmap.

---

# 1. Project Overview

The project analyzes Saudi data-related job postings to identify the skills, tools, roles, and requirements needed for students preparing for data internships and early-career opportunities.

The final outcome is a structured roadmap that connects market requirements with learning priorities.

---

# 2. Data Collection

The dataset contains 45 Saudi data-related internship and job postings collected from different data career categories.

The collected information includes:

- Job title.
- Company.
- City.
- Role type.
- Experience level.
- Required skills.
- Required tools.
- Job source.

---

# 3. Data Cleaning and Preparation

The dataset was cleaned and transformed before analysis.

The preparation steps included:

- Checking dataset structure.
- Detecting duplicate records.
- Reviewing missing values.
- Standardizing city information.
- Creating new analysis categories.

Additional columns were created:

- `city_cleaned`
- `experience_category`
- `role_category`

These transformations improved consistency and supported deeper analysis.

---

# 4. Exploratory Data Analysis

Exploratory analysis was performed to understand the Saudi data job market.

The analysis included:

- Distribution of opportunities by city.
- Role category analysis.
- Experience level analysis.
- Skills and tools frequency analysis.

---

# 5. Technical Analysis

The project analyzed job requirements to identify important technical areas.

Main analysis topics:

## Skills Analysis

Identified commonly required skills such as:

- Data Analysis.
- Reporting.
- Data Governance.
- Data Validation.
- Problem Solving.
- Data Visualization.

## Tools Analysis

Analyzed commonly requested tools including:

- SQL.
- Python.
- Power BI.
- Excel.
- Tableau.

## Role Analysis

Compared requirements across different career paths:

- Data Analyst.
- BI Analyst.
- Data Scientist.
- AI-related roles.
- Data Governance roles.

---

# 6. Visualization Development

The project used visualization techniques to communicate findings clearly.

Tools used:

- Matplotlib.
- Seaborn.
- Power BI.

Created visualizations for:

- Top tools.
- Top skills.
- City distribution.
- Role categories.
- Experience categories.
- Tools by role category.

---

# 7. Power BI Preparation

A dedicated dataset was prepared for dashboard development.

The Power BI dataset includes:

- Job roles.
- Cities.
- Experience categories.
- Skills.
- Tools.

The prepared file:

`saudi_data_jobs_powerbi.csv`

was created to support interactive dashboard development.

---

# 8. Career Roadmap Development

Based on the analysis results, the project developed a readiness roadmap with three levels:

## Beginner Level

- Python basics.
- SQL fundamentals.
- Excel.
- Data cleaning.
- Data analysis.

## Intermediate Level

- Advanced SQL.
- Statistics.
- Data modeling.
- Machine learning fundamentals.
- Power BI.

## Career Ready Level

- Real projects.
- GitHub portfolio.
- CV preparation.
- Interview preparation.
