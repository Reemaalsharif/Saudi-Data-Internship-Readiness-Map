# Project Findings

## Saudi Data Internship and Job Market Analysis

This document summarizes the main findings identified from analyzing Saudi data-related internship and job postings.

---

# 1. Required Tools Analysis

The analysis showed that SQL is the most frequently requested tool in Saudi data-related opportunities, followed by Python, Excel, Power BI, and Tableau.

These results indicate that students preparing for data careers should focus on:

- SQL for database querying and data management.
- Python for data analysis and automation.
- Power BI and Excel for reporting and visualization.

---

# 2. Required Skills Analysis

The analysis identified several important skills required in Saudi data-related roles.

The most common skills include:

- Data Analysis.
- Reporting.
- Problem Solving.
- Data Governance.
- Data Validation.
- Data Integrity.
- Dashboard Development.
- Data Visualization.
- Business Intelligence.

These findings show that data careers require both technical abilities and analytical/business skills.

---

# 3. City Distribution Analysis

The dataset analysis showed that Riyadh contains the highest number of data-related opportunities compared with other cities.

This indicates that Riyadh represents a major hub for data internships and early-career roles.

Other cities also contain opportunities, but with lower frequency in the collected dataset.

---

# 4. Role Category Analysis

The dataset contains multiple data career pathways, including:

- Data Analysis.
- Business Intelligence.
- Data Science.
- AI-related roles.
- Data Governance.
- Internship opportunities.

This highlights that students can enter the data field through different career paths depending on their skills and interests.

---

# 5. Experience Level Analysis

The analysis showed different experience requirements across postings, including:

- Internship opportunities.
- Entry-level roles.
- Mid-level positions.
- Senior roles.

For students preparing for internships, focusing on practical projects and building a portfolio can improve readiness.

---

# 6. Overall Findings

Based on the analysis, a strong foundation for Saudi data-related careers should include:

- SQL.
- Python.
- Data analysis.
- Data visualization.
- Power BI.
- Database concepts.
- Practical projects.

The findings were used to develop a structured readiness roadmap for Computer Science students interested in data careers.
